# Hardware

Capture-device implementation and the records used to choose and build it live here.

- `rootcap/`: iPhone head mounts.
- `ego-oscar-split/`: custom stereo-camera hardware, firmware, and receiver software.
- `hampo-rhb02bk-headset/`: enclosure and fabrication files for the Hampo camera board.
- `research/`: assessments, calibration notes, and procurement decisions for existing devices.

Generated release archives are not source files. Build or package them from the corresponding hardware directory when needed.
