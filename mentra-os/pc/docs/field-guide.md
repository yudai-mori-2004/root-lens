# 撮影データのアップロード手順

| 項目 | 内容 |
|---|---|
| 事業所 | ［事業所名］ |
| 困ったときの連絡先 | ［担当者名・連絡先］ |

## 初めて使うとき

事業所のフォルダから取り込みアプリと `rootlens-site.json` をダウンロードします。

- Windows では、ダウンロードしたファイル（`.exe`）を開き、画面に従ってインストールします。スタートメニューから **RootLens** を開きます。
- Mac では、ダウンロードしたファイル（`.dmg`）を開き、**RootLens Import.app** を「アプリケーション」へコピーして開きます。

Windows で「WindowsによってPCが保護されました」と表示された場合は、事業所の Drive から取得した
インストーラーであることを確認し、**詳細情報** → **実行**を選びます。実行できない場合は RootLens の担当者へ確認してください。

アプリの **設定** → **事業所の設定を読み込む** から `rootlens-site.json` を選び、事業所名を確認してください。
次回から設定は不要です。

## 録画を取り込む

スマートグラスの録画を止め、保存が終わるまで待ちます。電源を入れたまま USB ケーブルで PC につなぎ、
**RootLens** を開いて **接続** を押します。スマートグラス内の未アップロードの録画が一覧に表示されます。
アプリを開いただけでは、録画は表示されません。

## 映像と音声を確認する

左の一覧から録画を選び、右の画面で再生します。**前の録画**・**次の録画**で順に確認できます。

撮影を避けるよう指定された内容が含まれる場合や、映っている方・声が入っている方の同意を確認できない場合は、
アップロードせず RootLens の担当者へ確認してください。

## アップロードする

内容を確認した録画を選び、**アップロード**を押します。画面に進み具合が表示されるので、
「アップロードが完了しました」と表示されるまで待ってください。
完了した録画は一覧から外れます。
保存が確認できた録画は、スマートグラスから自動で削除されます。
途中でUSBが抜けた場合は、つなぎ直して **接続** を押してください。

アップロードすると、事業所としてこの録画の販売先への提供を承認したことになります。
事業所から承認を任された方が操作してください。
