# Task 20: Mentra field upload

## 目的

現場担当者が事業所の Google Drive にあるスクリーンショット付きの手順説明に従い、
Mentra Live の録画を USB で PC に取り込み、映像と音声を確認して「承認済みデータ」へ
アップロードできるようにする。PC には取り込みと再生に必要な部品を同梱したアプリを導入する。

## 読むべきファイル

- `desktop/README.md`（アプリの操作と責務）
- `desktop/rootlens_import/core.py`（USB 取り込みの正本）
- `desktop/rootlens_import/site.py`（事業所設定）
- `desktop/rootlens_import/library.py`（保存した録画の一覧）
- `desktop/rootlens_import/desktop.py`（録画一覧・プレビュー・画面操作）
- `desktop/rootlens_import/drive.py`（サービスアカウント認証・再開可能なアップロード・保存後の照合）
- `desktop/rootlens_import/upload_state.py`（録画ごとの送信位置と完了状態）
- `desktop/packaging/`（OS 別ビルド）
- `desktop/docs/`（現場での操作、PC の初回設定、管理者の運用）
- `desktop/docs/drive-layout.md`（共有ドライブの配置とリンク）

## 採用する手順

初回に事業所の `rootlens-site.json` を読み込む。このファイルには事業所名・保存先と、
その事業所専用のサービスアカウント認証情報を含める。

アプリを開くと PC に保存した未アップロードの録画が左側の一覧に表示され、選んだ録画を右側の画面で映像・音声とともに
再生できる。「前の録画」「次の録画」で続けて内容を確認する。

Mentra Live を USB でつなぎ、画面上部の「接続」を押すと、保存済みの録画を照合し、未取り込みの録画を追加する。
起動時は保存済み録画を表示し、USB 取り込みは「接続」から行う。端末を外した状態でも保存した録画を確認できる。

事業所から承認を任された担当者は、内容を確認した録画を選んで「アップロード」を押す。
アプリが事業所の「承認済みデータ」へ録画フォルダを作り、撮影アプリが作った
`rgb.mp4`、`frames.jsonl`、`imu.jsonl`、`metadata.json` の4ファイルを送る。
進捗をアプリに表示し、Drive 上の4ファイルを照合してから完了とする。完了した録画は通常の一覧から外す。
中断した場合は「アップロード」を押すと送信済みの内容と照合し、続きから送る。

現場合意書第5条第3項に従い、このアップロードが、事業所として撮影データを「承認済」とし、
販売先への提供を認める操作となる。撮影前の本人署名は別に取得・管理する。

## 構成と範囲

共有ドライブ RootLens の「撮影協力」に事業所ごとのフォルダを置き、事業所単位でアクセス権を分ける。
最初の事業所は BB SHEEP。その直下に `アップロード手順説明.pdf`、取り込みアプリ、事業所設定を置き、
子フォルダは「承認済みデータ」一つとする。「承認済みデータ」には各録画フォルダを直接アップロードする。
RootLens Datasets には、実際に外部へ共有しているデータセットを置く。

アプリは USB の取り込み、事業所設定、保存した録画の読み出し、Drive への送信と照合、送信状態、画面操作の責務を分ける。
現場で行う作業は、取り込み、再生確認、アプリからのアップロードとする。
アプリ内のチェック項目、担当者名・同意書番号の入力、バッチの作成、承認記録ファイルの生成は設けない。
撮影アプリの4ファイル契約と iPhone の既存フローは変更しない。

サービスアカウントは事業所ごとに専用のものを用意し、当該事業所フォルダだけに権限を付ける。
認証情報をアプリ本体へ埋め込まず、事業所の制限付きフォルダで統合 JSON を配布する。
完了状態はアプリ内へ記録し、録画フォルダには追加ファイルを入れない。
端末と PC の元データは保持する。アップロード完了後は通常の一覧から外し、原本は削除しない。

RootLens は匿名化処理後の確認用リンクと完了日時を事業所へ案内し、現場合意書第5条第4項に従って
匿名化処理の完了後7日間は販売先へ提供しない。期間の起点は匿名化処理の完了日時である。
この案内と販売先への提供前の確認は RootLens 側の運用として検証する。

## サトウカエデの追加と実アプリでの全録画アップロード

通常の手順は、各PCにアプリを入れて初回だけ事業所の設定JSONを読み込み、以後は
スマートグラスをUSBでつないで「接続」を押し、録画を確認して「アップロード」を押す流れである。

アップロード関数の直接呼び出しや設定ファイルの書換えで実操作を代用していない。

初回の記録範囲から、各録画の個数・総容量までの照合に限る。PCと端末の原本は削除していない。
