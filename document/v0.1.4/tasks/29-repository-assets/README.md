# 29. Repository assets

## 目的

共有契約、生成物、個人ファイル、ローカルデータを、それぞれの用途に合う場所へ分ける。

## 変更

- 複数の実行環境が検証に使うsource manifestのテストベクトルを`tests/`へ移した。
- 事業資料の生成先を`progress/business/`へ統合し、Claru向け資料をそのアーカイブへ移した。
- 個人の応募書類をリポジトリ外の`Downloads/RootLens-Archive/`へ移した。
- 旧DBバックアップ、廃止済みの鍵、部分展開されたサンプルデータ、サンプル配布ZIPを削除した。

## 成功基準

- 共有契約を参照する全テストが移動後のパスを使う。
- `progress/`が事業資料、ピッチ用サイト、プロモ動画に分かれている。
- リポジトリ直下に`backups/`、`fixtures/`、`keys/`、`sample/`、サンプル配布ZIPが残っていない。
