## 修正範囲

- 開始前の正常な取消を明示し、録画開始後の本当の保存失敗を成功へ変換しない。
- MediaRecorderの非同期エラーとCamera2の準備例外を捕捉し、フレーム通知停止を検知する。
- 命令IDの保存に失敗しても録画停止を実行し、同じ停止操作の再送で録画を再開しない。
- ファイル内容の同期後に完成metadataを公開し、途中フレーム欠落を正常なカメラ時刻の対応として書かない。
- 今後のmetadataへ、実際に動作した撮影アプリの版を記録する。
- 更新用スクリプトは撮影・保存・キャリブレーションのサービスが動いている場合、上書き前に中止する。

更新前の確認は操作ミスを防ぐためのもので、外部から直接行うADBのinstallや、確認直後の
新しい撮影開始を原子的に禁止する機能ではない。更新が終わるまで撮影操作は行わない。
突然の電源断を防げることや、5時間の実機連続録画が検証済みであることは主張しない。
