# 頭部への配置とケーブル処理

## 採用する保持構造

初号機は、発注表の幅25 mm・厚さ1 mmの薄型ソフト面ファスナーから頭部支持輪を作り、その上から普通のキャップを被る。キャップは外観を隠し、荷重は内側の輪が受ける。眼鏡やサングラスはカメラの重量を受けず、普段どおり独立して掛ける。

```text
                  [カメラバー]
                 42 mm、斜め下18°
                       │
       左こめかみ ─── 額支持 ─── 右こめかみ
          │                            │
          │                     [映像処理・無線・
          │                      センサー制御基板]
          │                            │
          └──────── 後頭部 [電池＋昇圧基板]
```

輪は額の左右、両耳の1〜2 cm上、後頭部の出っ張りの下の五点で当てる。前後方向の補助帯を頭頂へ一本通す。これで前のカメラが下へ回る力を、後頭部の40 g電池で相殺する。鼻、眼鏡ブリッジ、耳へ電子部品の重量を預けない。

## 部品の位置

| 位置 | 載せる物 | 固定 |
|---|---|---|
| 額中央、眉より25〜35 mm上 | 42 mm基線のステレオカメラ、慣性センサー | 5×7 cmユニバーサル基板一枚を70×35 mmへ切った支持板へ固定。カメラと慣性センサーを同じ板に留める |
| 右耳の20〜40 mm後ろ | 映像処理基板、無線基板、センサー制御基板、microSD、3.3 V電源 | ユニバーサル基板を60×32 mmへ切り、外寸65×38×18 mmの通気カバー内へ置く。アンテナ面を外側へ向け、頭皮との間に3 mm空間 |
| 後頭部中央 | 2000 mAh電池、Lipo Rider Plus | 左右方向105×高さ50×厚さ15 mmの柔らかいポケット。57.5×34.5 mm電池と41×25 mm昇圧基板を左右へ並べ、間に幅5 mmの縫い目を入れる |
| 左耳後ろ | 配線の余長10〜20 mm | 面ファスナー下へS字一回だけ。輪にしない |

カメラの光軸は水平から下へ18°を初期値にする。立位で1 m前方の床と両手が下半分へ入り、正面の物体も上半分へ残る角度である。支持板と支持輪の間に入れる面ファスナーの積層差で11〜25°へ変えられる。レンズ同士の角度は動かさない。

## ケーブルの長さと経路

首より下へ線を出さない。線はすべて支持輪の内側またはキャップの縫い代へ沿わせ、30〜40 mmごとに柔らかい糸ループまたは面ファスナーで留める。

| 区間 | 仕上がり長さ | 線 |
|---|---:|---|
| カメラから右耳後ろ | 200 mm | DECXINへ同梱を指定するUSB 2.0 High Speedシールドケーブル。D+/D−を自作の単線にしない |
| カメラ露光同期端子からセンサー制御基板 | 240 mm | 28 AWG黄＋黒を撚った一対 |
| 慣性センサーからセンサー制御基板 | 240 mm | 28 AWGの赤（3.3 V）、黒（接地）、緑（データ）、青（クロック）の四本を緩く撚る |
| センサー制御基板から映像処理基板 | 60 mm | 28 AWGの緑（送信）、青（受信）、黒（接地）。両端へ機能名を書いた熱収縮チューブを付ける |
| 後頭部電源から右耳後ろ | 200 mm | 24 AWG赤黒を撚る。5 V幹線一本をケース入口で星形分岐 |

頭を左右へ最大に向けても線長は変わらない。キャップと頭が一緒に動くため、Mentra Liveで問題になった首から腰までのケーブルの引っ掛かりは発生しない。余長は後頭部ではなく左耳後ろへ10〜20 mmだけ置き、家具や腕が入る輪を作らない。

## 重量配分

カメラと慣性センサーを除く計算・電源部分は次の見積りになる。

| 部分 | 重量 |
|---|---:|
| 映像処理基板＋無線基板 | 公称4.3 g |
| センサー制御基板 | 2〜3 g |
| 電池 | 公称40 g |
| Lipo Rider Plus | 8〜12 gの見積り |
| USB-A変換基板 | 公称2.5 g |
| 3.3 V電源基板 | 公称1.8 g |
| microSD基板＋カード | 約2 g |
| USBレセプタクル、状態表示LED、ケーブル | 約2〜3 g |
| 配線、支持板、ケース | 12〜20 g |
| 合計 | **75〜85 g** |

このうち前頭部にはカメラと慣性センサーだけを置く。約7〜8 gの処理基板群を耳の後ろ、約50 gの電池・昇圧部を後頭部へ移す。眼鏡型の意味を残す箇所は視線に近いカメラ位置であり、保持は眼鏡へ押し付けない。

## ケースの熱と操作

映像処理ケースは完全密閉せず、上下に各20 mm²以上の開口を設ける。スイッチサイエンス注文に含めた17×17×6 mmヒートシンクを付属熱伝導シートで映像処理基板の主処理チップへ貼り、フィンを外側へ向ける。皮膚側はユニバーサル基板と二枚のソフト面ファスナーで隔てる。電池とヒートシンクを重ねない。主電源は後頭部のLipo Rider Plusスイッチを外から押せる位置へ置く。

後頭部の主電源を入れると、カメラ、microSD、慣性センサーの初期化と応答確認を行い、そのまま録画を始める。状態表示は一個のNeoPixelモジュールへまとめ、起動中は白の明滅、録画中は黄色の点滅、停止処理中と停止完了後は黄色点灯、カメラ・microSD・慣性センサーの失敗時は赤点滅とする。停止はiPhoneから指示し、`DONE`を受け取った後に無線転送を始める。LEDは作業中に目へ直接入らないよう外後方へ向ける。

## 装着時の調整

1. 電源を切った状態で後頭部の締め具を調整し、下を向いても輪が眉へ落ちない強さにする。
2. カメラ支持板を中央へ合わせ、左右レンズを水平にする。
3. 電池位置を後頭部中央で上下10 mm動かし、前後の回転が最小になる位置へ固定する。
4. USB線と信号線を留め、指一本が入る大きな輪が残っていないことを確認する。
5. キャップを被り、右耳後ろのケースと後頭部電池を内側のくぼみへ収める。
6. しゃがむ、棚へ手を伸ばす、首を左右へ振る動作を行い、カメラ角度と線の位置が変わらないことを確認する。

この構造なら、外から見えるのはキャップ前面の小さな42 mmカメラバーだけになる。眼鏡へ挟む支持具は外し、眼鏡を交換しても収録系の位置と校正を保てる。

## 支持輪を発注材料から作る寸法

1. ソフト面ファスナーのループ側を650 mm切り、毛のある面を外側へして頭部の輪にする。
2. フック側を120 mm切り、輪の右後端へ60 mm重ねて二列縫う。残る60 mmでループ面を掴み、頭囲520〜620 mmを調整できるようにする。
3. ループ側を360 mm、フック側を80 mm切り、額中央から後頭部中央へ通る頭頂補助帯を同じ方法で作る。前端と後端は支持輪へ25×25 mmの四角と対角線で縫う。
4. カメラ支持板はユニバーサル基板を70×35 mmへ切り、四隅を半径3 mmに丸める。中央を支持輪の外側へ25×20 mmの範囲で縫い留める。支持板との接触線を上下15 mm離し、上側へ25×20 mmのループ材を三枚、下側へ同じ物を八枚重ねる。厚さの差5 mmから`atan(5÷15)=18.4°`となる。下側を六枚にすれば11.3°、十枚にすれば25.0°になる。
5. カメラ基板は支持板の既存穴へ通したポリエステル糸を左右それぞれ二周させて留める。レンズ座と部品には糸を掛けず、基板外周だけを押さえる。慣性センサーはカメラ基板の中央寄りへポリイミドテープと二本の糸で固定する。
6. 電池ポケットはループ側を105 mmずつ四本切り、長辺を突き合わせて縫い、105×100 mmの一枚にする。これを半分に折って左右端を縫い、105×50 mmの袋にする。左端から60 mmの位置に縦の仕切りを縫い、57.5×34.5 mm電池と41×25 mm昇圧基板が直接触れないようにする。上端はフック側105 mmを一本横向きに重ねて閉じる。
7. 右側の基板台はユニバーサル基板を60×32 mmへ切り、角を丸める。支持輪との間へループ側65 mmを二本並べて縫い、皮膚側スペーサー兼絶縁層にする。部品面の上はループ側65 mmを二本並べた65×50 mmの覆いを被せ、上下辺を開けて通気口にする。

標準18°で使うループ側の合計は1,910 mm、フック側は305 mmで、発注する各2 mの一組に収まる。最大25°へ変えた場合もループ側は1,950 mmで収まる。

切断したガラス繊維基板の粉を吸い込まないよう、切断と研磨は保護眼鏡と防じんマスクを着けて屋外で行い、切断面を水拭きしてから頭部支持輪へ付ける。
