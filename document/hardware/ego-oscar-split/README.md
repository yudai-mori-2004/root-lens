# Ego-OSCAR無線ヘッドデバイス

> **2026-09-11の初号機変更:** M5Stamp ESP32P4案は小型化の第二段階へ移した。UVC 2560×720・30 fpsの持続受信、Motion JPEG復号、H.264圧縮、5時間のmicroSD書込み、発熱を実機で確認できていないため、初号機の演算・保存にはRaspberry Pi 5 / 1 GBを使う。カメラ、XIAO ESP32-S3、ICM-20948、露光同期は維持する。現在の購入品、Pi配線、価格は[低価格経路の採用判断](../existing-glasses/LOW-COST-DECISION-2026-09-11.md)を正とし、書込み可能な差分・設定・テストは[Raspberry Pi 5初号機実装](pi5/README.md)に置く。以下は頭部完結型へ小型化するための実装記録として残す。

このディレクトリは、Ego-OSCARの同期ステレオカメラ、露光同期信号、慣性センサー取得を保ったまま、腰までのケーブルをなくす案の設計と実装記録である。以下は2026-09-07に選んだ頭部完結型の構成であり、現在の初号機ではない。

```text
同期ステレオカメラ ─USB 2.0─ 映像処理基板 ─専用コネクター─ 無線基板 ))) iPhone
        │                         │
        └露光同期信号─ センサー制御基板 ─UART─┘
                         │
                    ICM-20948

256 GB microSD ───────── 映像処理基板
2000 mAh電池 ─充電・5 V昇圧─ 全体
```

映像処理基板は **M5Stamp ESP32P4**、無線基板は **M5Stamp ESP32P4用Wi-Fi 6拡張モジュール**、センサー制御基板は **Seeed Studio XIAO ESP32S3** を使う。以後の文書では役割名で記す。

カメラが出す左右一体の2560×720、毎秒30枚のMotion JPEGを映像処理基板で復号し、左右それぞれ1280×720、毎秒30枚、6メガビット毎秒のH.264へ変換する。二本の映像と慣性センサー行を5分単位の`EOS2`ファイルへ入れ、録画中はmicroSDだけへ書く。iPhoneは停止操作の完了後に無線で全チャンクを受け取る。この順序により、録画中に同じmicroSDを読み書きして帯域を奪い合うことがない。

作業順は以下。

1. [一括カートリンクと注文手順](ORDER.md)から国内二店の部品を手配し、品目の詳細は[発注表](BOM.md)で照合する。カメラは仕様確認文を注文前に送り、42 mm基線、映像モード、色差間引き、露光同期端子を注文書へ記載させる。
2. [端子別配線表](WIRING-NETLIST.md)を上から順に使い、電源系、USB、センサー制御基板、microSD、二種類のLEDを組む。処理の根拠とファイル形式は[配線・処理設計](WIRELESS-DESIGN.md)にまとめた。
3. [ファームウェア手順](firmware/README.md)で、映像処理基板とセンサー制御基板の二本をビルドして書き込む。映像処理はJPEG復号とH.264圧縮を二重バッファで重ね、左右を別画像へコピーしない。
4. [iPhone受信ライブラリ](receiver-ios/README.md)をRootLensアプリへ追加する。停止完了を受け取った後に全チャンクを順番に取得し、検査済みのファイルだけを確定名へ切り替える。
5. 収録後、[`eos2_extract.py`](tools/eos2_extract.py)で左右のH.264と慣性センサー記録を復元し、必要なら横並びのMP4を生成する。
6. [装着設計](WEARABILITY.md)に従い、カメラを前、処理基板を耳の後ろ、電池を後頭部へ分散する。首より下へケーブルは延ばさない。

固定した数値は、左右各1280×720・30枚/秒、合計12メガビット/秒、最大18メガビット/秒、キーフレーム間隔60枚、5分分割、慣性センサー180 Hz、TCP 47000番、頭部アクセスポイント`192.168.4.1`。型番と選択肢まで固定した商品価格は約49,176円、カメラ送料と輸入時費用を含む初号機予算は52,200〜57,200円。カメラと慣性センサーを除く重量は75〜85 g、2000 mAh電池で約90分を設計値とする。90分の収録量は通常設定で約8.1 GB、無線転送は22.5メガビット/秒で約48分である。

比較調査は[`ALTERNATIVE-DEVICES.md`](ALTERNATIVE-DEVICES.md)、カメラ同定の根拠は[`CAMERA-IDENTIFICATION.md`](CAMERA-IDENTIFICATION.md)に残す。ROCK 5CやRaspberry Piを身体側に置く案は今回の配線には使わない。
