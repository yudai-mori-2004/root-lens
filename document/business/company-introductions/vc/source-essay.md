# RootLens

## 私たちは現場データ収集から始めるフィジカルAIプレーヤーになる企業である

---

## 1. フィジカルAI業界の構造

### 垂直統合型

現在、多くのフィジカルAI企業はロボットと現場を垂直統合する形で研究開発を進めている。特定の業種・タスクに絞った上で、決め打ちでとにかく現場で実際に動くロボットを作ろうとする場合が多い。タスクの難易度が高い場合、完全な自律運用はまだ難しい部分が多いため、まずは遠隔操作で働くレベルでサービスとして商用化に進むケースもあれば、地道に自律運用の幅を広げるために研鑽を重ねる企業もある。1X等が該当する。

なお、垂直統合と水平展開の両方の性質を持つ企業もある。Genesis AI等は、AI・ハードウェア・データエンジンをフルスタックで自社開発しつつ、特定業種に絞るのではなく汎用的なロボティクスプラットフォームを目指している。

### 水平統合型

垂直統合型の企業とは対照的に、水平統合型の企業がある。垂直統合型のバリューチェーンを分解するイメージであり、現在多くのレイヤーが存在する。

**データ収集層**
人間の作業データの収集に特化している企業、テレオペレーションや合成データの生成を行う企業、そして生データをフィジカルAIの学習に直接使えるデータに加工する企業などがある。最近はデータ収集企業の増加に伴い、さらに上流として収集に特化したデバイスを開発する企業も広がりはじめている。

**基盤モデル開発層**
主にPhysical Intelligence（PI）やNVIDIAが挙げられる。桁違いの投資ができる企業に限られる領域である。また、近いレイヤーにシミュレーション・デジタルツイン層がある。これは基盤モデルと対立するアプローチではないが、現実世界をシミュレーション環境に再現することで現実世界におけるデータの必要量を下げつつ、そのままシミュレーション環境でモデル開発まで一気通貫で進めるアプローチである。

**ハードウェア開発層**
特に中国系の企業が安価なロボットを提供するという面で強く、Unitree等が筆頭である。

**現場統合層**
既存のロボットやモデルを積極的に利用し、現場への統合を優先する企業。この領域は国内にもスタートアップが多い。

## 2. 私の仮説：最終的に勝つのは「現場を含むフィードバックループ」を持つ企業である

私の考えでは、将来的に主流になるのは、モデル開発・ハードウェア開発・現場統合という3つの領域を自社のループとして持ち、実際に現場でロボットを稼働させている企業である。

理由は、ロボットシステムのフィードバックループがこの3つで完結するからである。現在は独立したレイヤーとして存在している「データ収集」は、将来的にはこのループの中に吸収される。なぜなら、現場に統合されたロボットの実機が稼働すること自体がデータ収集になるからである。物理世界にフィジカルAIが投入されはじめた瞬間から、データは「外部の企業がわざわざ収集するもの」から「ロボットの稼働を通じて自動的に蓄積されるもの」に変わり、そのデータが直結したフィードバックとしてモデルの改善に使われる。したがって、この一連のループを自社で持つ企業が最速でロボットを改善でき、最終的に生き残る企業になると考える。

## 3. だからこそ「現場データ収集」から始める

ここまでの議論を踏まえると、独立したデータレイヤーは将来消滅するのだから、データ収集企業に未来はないように聞こえるかもしれない。しかし私の考えは逆で、むしろデータ収集こそが最も有利な出発点であると考えている。

先ほどの水平統合・垂直統合の企業をそのまま図に表すと、大まかに、カバーしている範囲が横方向に広いほど多くの現場と繋がっており、縦方向に広いほど多くの技術や領域を網羅しているという構図になる。この図の中で、直接ロボットが利用される現場と接触があるのは、一番下の現場統合層である。これは当然である。

しかし実はもう一つ、現場と直接接触しているレイヤーがある。一番上流のデータ収集層の中でも、現場データの収集を行う企業である。データ収集のためには現場に入り込む必要があり、結果として、将来ロボットを導入する可能性がある現場と直接の関係を築くことになる。

これは一見不思議な構造である。一般的に産業における上流工程の企業が直接最下流の顧客と接することは珍しい。しかし、フィジカルAIでは現場の実データが不可欠であるという特殊な事情から、上流と最下流が直接繋がる。

### 現場データ収集層が持つ構造的優位性

以下の点から、現場データ収集層は今の段階で独自の優位性を築くことができる。

**横方向の網羅性は、今の技術レベルでも実現可能である。**
現場統合層で横方向（複数の業種・現場）を網羅できている企業は現時点で一社もない。ロボットの自律動作は業種・タスクごとに個別の技術開発が必要であり、横に広げることが極めて難しいからである。しかし、現場データ収集層であれば話は別である。データ収集はカメラを装着した人間の作業を撮影するだけであり、業種を跨ぐ技術的障壁がほとんどない。つまり、今の時点で横方向を網羅できる唯一のレイヤーがデータ収集層である。

**現場は有限の資産であり、先行者優位が極めて強い。**
あらゆる業種——飲食、小売、製造、配送、建築、美容、農業——途方もない数の現場がこの世界にはあるが、有限であることには変わりない。先にどれだけ多くの現場と繋がることができるかが重要である。一つの現場が複数のデータ収集会社と契約を結ぶことは考えにくい。現場側にとっては、撮影機材の管理やスタッフへの説明、プライバシーに関する合意の対応など、一社と契約するだけでも相応の負担が発生するためである。これは早いもの勝ちの勝負であり、実際に海外では急速に広まっている。一方、日本ではまだほとんど浸透していない。

**現場ネットワークは、ロボット企業にとって不可欠なものになる。**
遅かれ早かれ、ロボット企業が最終的な顧客である現場のネットワークを取りに来ることは確定的である。現場を含めたフィードバックループを作ることが最速の勝ち筋だからである。そして、現場ネットワークを得るには多業種に渡って様々な同意やコンプライアンス対応を積み重ねる必要があり、後発が容易に真似できない参入障壁になる。

**現場データの先行取得は、自らが現場統合者になるための布石でもある。**
ロボットを各現場に導入するにあたっては、導入判断や導入後の調整のためにも、既存の人間のワークフローを詳細に把握する必要がある。これは技術的にも多大な手間がかかる工程である。もし現場のデータをすでに収集完了している企業があれば、ロボット企業にとっては一からワークフロー調査をやり直す必要がなくなるため、協業の相手として自然に選ばれる立場になる。そしてさらに重要なのは、この立場にいるということは、他のロボット企業の動きを待つまでもなく、自分たち自身がロボットの現場統合に乗り出せるということである。つまり、現場データ収集から始めた企業が、最終的には現場統合を行う企業へと進化できる。これが私たちの長期的な構想である。

### RootLensの方向性

整理すると、私たちの構想は2段階である。

第1段階として、現場データネットワークを広げることで、データ収集・販売による収益を確保する。これは今すぐ始められるビジネスであり、現場との関係構築と多業種へのコンプライアンス対応を通じて、後発が真似できない参入障壁を積み上げていく。

第2段階として、蓄積した現場データ・現場ネットワーク・現場に関する知見を武器に、自らロボットの現場統合に乗り出す。セクション2で述べた「モデル開発・ハードウェア開発・現場統合のフィードバックループ」を自社で持つ企業へと進化する。

この方向性を一言で表したのが、「現場データ収集から始めるフィジカルAIプレーヤー」である。現場は有限の資産であり、先に押さえたもの勝ちである。フィジカルAIにおいて最も重要な資産とも言える。

## 5. これまでの活動実績

### 現場開拓

- 30件ほどの現場への飛び込み営業を実施。
- 飛び込み営業を通じて出会ったベーカリーの経営者（川島）の許可のもと、その店舗で実際にデータ収集のテストを行った。特に、現場で実際に機材を装着したスタッフから逐一フィードバックをいただき、撮影機材の改善を繰り返した。
- ベーカリーで合計50時間ほどのデータを収集。
- SNSのDMを通じて複数の飲食店に連絡し、神戸のカフェチェーンと一社、合意の手続きを進めている。
- 大崎（チーム体制の項を参照）の紹介で、関西のスーパーマーケットチェーン（とみづや）を一社ご紹介いただき、撮影協力について9/17に直接オフィスに説明に伺う予定。

### 販売先開拓

- ベーカリーで収集したデータをサンプルとして、海外8社（FPVlabs、Claru、CortexAI、ScaleAI、ShaipAI、Hyphenbox、PeekAI 等）とやり取りを進め、実際にサンプルのやり取りまで至った。ただし、合意を結ぶまでには至っていない。原因は、私たちの収集スケールが世界的に見てまだ規模が小さいため、低い優先度として扱われているためである。より規模の大きい収集会社が、インドをはじめラテンアメリカでも急速に広がっていると聞いている。
- 国内の販売先を探す中で、Nextremer株式会社から話をいただいた。近日中にフィジカルAI向けのデータの加工および販売を行うサービスが展開される予定で、そこにデータを掲載することになる見込みである。現在は、当社側の現場合意書のシステム構築に加え、Nextremer側との間で現場合意の取り方のフローを擦り合わせている段階である。Nextremerはデータ加工レイヤーの企業であるため、ここにデータを経由させることで、プライバシー処理周りの責任の分散や、高度なアノテーション付きデータを求める販売先へのアプローチが可能となる。加えて、Nextremerにデータを格納する形を取ることで、自社でのストレージコスト（月10,000時間規模では50〜150TBに達する）を大幅に抑えることができ、資本効率と運用負担の両面で大きなメリットがある。

**大崎**：川島の紹介で繋がった。三菱UFJ銀行で長年キャリアを積んだのち、関西スーパーマーケットに転じて常務取締役・管理本部長として上場企業の経営管理を統括してきた経歴を持つ。会社の立ち上げにかかる相談・アドバイス、契約書や合意書の書面添削・確認の補助、および小売業界・製造業界に持つ広範なネットワークを活用した現場開拓の支援を担っている。

### 撮影デバイスの進化

- 撮影デバイスを拡充した。初期のスマートフォンヘッドマウントの段階から、マウント器具を3Dモデルからゼロベースで設計し、重量バランスや装着時の快適性を最適化してきた。その後、スマートグラスによる撮影も導入した。現場（ベーカリー）でテストしたところ、フィードバックは明らかに変わった。「これならつけてもいい」と言ってくれるスタッフが増えた。軽く見た目に違和感が少ないデバイスとそうでないデバイスでは、想定以上に現場の許可を左右する要素であることが分かった。長時間装着するという性質上、デバイスの快適性は現場拡大において極めて重要な要素である。
- エゴセントリックデータ収集専用のデバイスや専用モジュール部品がここ最近増えてきており、私たちの重要な課題として「現場の負担を最小化する撮影デバイスの改善」が浮上している。
- 専用の軽量撮影デバイスを試験的に購入しているほか、負担の少ない形状で熱問題・バッテリー問題を解決できる撮影デバイスの開発を実際に開始している。そもそも撮影機材は、カメラの構造やセンサーデータの内部処理を含め、様々な研究を通じて厳格な要件があり、エゴセントリックデータの収集に特化したデバイスが求められている。

## 6. ユニットエコノミクスと財務構造

### 前提

| 項目 | 数値 |
|---|---|
| 売上単価 | 1,600円/h（下限） |
| 現場還元 | 売上の50%（= 800円/h） |
| 会社の取り分 | 800円/h |
| デバイス | 8万円/台、10ヶ月償却 → 8,000円/台/月 |
| 1台あたり月間稼働 | 1日5h × 22営業日 = 110h/台/月（中間シナリオ） |

### スケール別PL

**月500時間（2026年10月目標）**

| 項目 | 金額 |
|---|---|
| 売上（会社取り分） | 500h × 800円 = 40万円/月 |
| 必要デバイス台数 | 5台 |
| デバイス償却 | 5台 × 8,000円 = 4万円/月 |
| 初期デバイス投資 | 5台 × 8万円 = 40万円 |
| 粗利（デバイスコスト控除後） | 36万円/月 |

デバイス償却が会社取り分を圧迫する割合は10%。売上総額（1,600円ベース）に対する粗利率は、現場還元・デバイス償却後で約45%である。

**月1,000時間（2026年12月目標）**

| 項目 | 金額 |
|---|---|
| 売上（会社取り分） | 1,000h × 800円 = 80万円/月 |
| 必要デバイス台数 | 10台（約4店舗） |
| デバイス償却 | 10台 × 8,000円 = 8万円/月 |
| 初期デバイス投資 | 10台 × 8万円 = 80万円 |
| 粗利（デバイスコスト控除後） | 72万円/月 |

**月10,000時間（中期目標）**

| 項目 | 金額 |
|---|---|
| 売上（会社取り分） | 10,000h × 800円 = 800万円/月 |
| 必要デバイス台数 | 91台（約30店舗） |
| デバイス償却 | 91台 × 8,000円 = 72.8万円/月 |
| 初期デバイス投資 | 91台 × 8万円 = 728万円 |
| 粗利（デバイスコスト控除後） | 約727万円/月 |
| 年換算 | 約8,720万円/年 |

デバイス償却は会社取り分に対して約9%であり、500h時点（10%）とほぼ同水準である。デバイス台数と売上は収集時間に比例するため、デバイスコスト比率はスケールしても大きくは変わらない。一方、規模の経済が効くのは人件費や固定費の按分であり、一度契約した現場が継続的にデータを出し続ける構造が実現すれば、新規開拓コストを抑えながら収集時間を伸ばせる。30店舗の確保は、既存のベーカリー（川島）＋神戸のカフェチェーン＋とみづやスーパー＋SNS経由の新規というパイプラインで見ると、2027年Q1前後に到達しうるレンジである。

### アップサイドシナリオ（複数回販売）

データは在庫として積み上がるため、同一データを複数のバイヤーに販売できる可能性がある。

- 平均販売回数が2回になれば、月10,000h体制で月間売上1,600万円。
- 平均販売回数が3回なら月2,400万円。
- 月10,000hを1年間継続すれば12万時間のデータ資産が蓄積され、年間売上ベースで1〜3億円の射程に入る。
- Nextremer経由で高付加価値化（アノテーション付き）された場合、実質単価がさらに上がる可能性もある。

### このモデル最大の武器：データのストック性

データは在庫として積み上がっていき、過去に収集した分も売り続けられる。月ごとのフロー売上に加えて、累積時間がそのまま資産として蓄積される。月次PLの粗利率に加えて、「累積データ資産の価値」がこの事業の本質的な価値を構成する。

### デバイスコスト以外に想定されるコスト

デバイスコストだけを見ると綺麗な数字であるが、他にもコストが存在する。

**ストレージ・転送費**
エゴセントリック映像は1時間あたり5〜15GB程度と想定される。月500hなら2.5〜7.5TB。ただし、Nextremerにデータを格納する形を取るため、自社負担は大幅に軽減される。

**現場開拓・維持の人件費**
これが本命のコストである。飛び込み営業、契約、機材の配布・回収、スタッフへの説明、トラブル対応、データチェック。現段階は創業メンバーが自分たちの時間で吸収しているが、月1,000h、2,000hとスケールする際に、この人件費がリニアに伸びるのか、それともある程度まで固定費で済むのかがユニットエコノミクスの分岐点になる。ここは要注意の領域である。一方、一度契約した現場が継続的にデータを出し続けてくれる形（新規開拓せずとも収集時間だけ伸ばせる構造）が実現すれば、粗利率は上がっていく。この継続性については、川島のベーカリーでの実績（収集時間の推移と継続性）から検証を進めている。

**デバイス破損・紛失**
現場で長時間使う消耗品的な性質があるため、8〜10ヶ月の償却期間は適切に見直す必要がある。

**契約・法務**
現段階では大崎が吸収しているが、規模拡大時には法務チームや外部弁護士のコストが発生する。

### スケール時の3つのボトルネック

デバイスコストとストレージがほぼ問題にならない以上、月10,000時間へのスケールにおけるボトルネックは以下の3点に集約される。

1. **現場開拓のスピード。** 30店舗を確保する営業リソース。最初の1店舗を取るのに何ヶ月かかったか、2店舗目は？という具合に、獲得サイクルが短縮していくかどうか。
2. **現場運用の負担。** 30店舗にデバイスを配布・回収・トラブル対応する運用体制。人力頼みだと店舗数×定期訪問という体制になり、人件費が膨らむ。
3. **買い手側の受け入れ規模。** 月10,000hを継続的に売り切れる販路（Nextremer、海外Scale/Claru等、国内需要）が確保できるか。

### VC向けサマリ

月10,000h体制の場合、売上総額（1,600円ベース）は年間約1.92億円、うち会社取り分は約9,600万円である。デバイス償却後の粗利率は売上総額ベースで約45%、初期デバイス投資は約730万円で月次粗利1回分以下で回収可能である。ここに現場開拓・運用の人件費（月4〜6人＝人件費150〜250万円程度）を差し引いても、営業利益6,000万円前後が残る計算になる。SaaSの水準からは見劣りするが、データ資産が累積で残るビジネスであり、バリュエーション上はストック性を評価してもらう議論になる。数字だけで言えば、デバイスコストは全く問題にならない。ここは強く出せるポイントである。
