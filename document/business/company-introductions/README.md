# 会社紹介資料

会社紹介資料を、相手と目的ごとに分けて管理する。

## VC向け

- 原本エッセイ：`vc/source-essay.md`
- 完成資料：`output/presentations/会社紹介（VC向け）.pptx`
- 制作ソース：`.codex-build/company-introduction-vc/create_deck.mjs`

原本エッセイは、VC向け資料を作り始めた時点の長文原稿をそのまま保存する。スライド制作中に受けた修正は完成資料へ反映されている。

## 現場向け

VC向けとは読者と目的が異なるため、原稿・完成資料・制作ソースを別に管理する。

- 構成原稿：`field/source-outline.md`
- 完成資料：`output/presentations/会社紹介（現場向け）.pptx`
- 制作ソース：`.codex-build/company-introduction-field/create_deck.mjs`
