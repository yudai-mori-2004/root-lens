# 撮影参加に関する同意書

RootLensを運営する森 雄大（屋号：moodai。以下「運営者」）は、現場での仕事の様子を動画撮影し、そのデータを国内外の企業や研究機関（以下「販売先」）に提供・販売することで、AIやロボットに関する技術の研究および開発に役立てます。
この同意書は、撮影機材の装着をお願いする方、撮影中に映像や音声が記録される可能性のある方に、撮影やデータの利用等について確認していただくものです。

## 第1条（撮影するもの）

1. 作業中の動画（映像と音声）
2. 撮影機材の動きや向きを記録するIMUセンサーデータ

## 第2条（撮影データの用途）

1. 運営者は、撮影データを、AIやロボットに関する技術、製品、サービスの研究、学習、評価、検証、改善および開発の目的に限って利用し、この目的に必要な範囲で、撮影データを保管・複製・加工・分析します。また、販売先に撮影データを提供・販売する場合も、販売先での利用は同じ目的の範囲に限ります。

2. 撮影データを一般の方がアクセスできる状態で公開する場合は、別途、撮影場所の管理者と対象となる方の同意を取得します。

3. 撮影データを研究・開発に利用する場合であっても、次の目的には利用せず、販売先にもこれらの目的での利用を認めません。

  1. 映っている方の特定、再特定または追跡
  2. 勤務状況の監視、人事評価、採否の判断
  3. 撮影データそのものを広告や娯楽のために公開すること

4. 撮影に同意していない方や、撮影を避けることにした場所・場面・物品が含まれるデータは、販売先に渡す前に提供対象から除外します。

## 第3条（参加の中止と削除）

1. 撮影に参加するかどうかは、本人が自由に決められます。
2. 一度同意した後でも、今後の撮影への参加を中止することができます。

3. 販売先に渡す前の撮影データについては、運営者に削除を求めることができます。運営者は、対象となる撮影データを確認し、提供対象から除外したうえで削除します。販売先に提供済みの撮影データについて削除の申し出を受けた場合、運営者は、対象となる撮影データを特定できる範囲で、販売先にそのデータの利用停止と削除を求めます。ただし、販売先での利用状況によっては、提供済みの撮影データをすべて回収・削除できない場合があります。また、撮影データがすでにAIの学習に利用されているときは、その影響を学習結果から完全に取り除くことが技術上困難、または不可能な場合があります。

4. 運営者は、同意の記録として、氏名、勤務先、同意日時を保存します。撮影場所の許可と本人の同意を確認するため、必要な範囲でこの記録の全部または一部を販売先に提示することがあります。

## 第4条（同意の確認）

1. 作業中の動画（映像と音声）とIMUセンサーによるデータが記録されることに同意します。
2. 撮影データが上記の目的に従って保管・複製・加工・分析されることに同意します。
3. 撮影データが、上記の目的に従って利用され、販売先へ提供・販売されることに同意します。
4. 同意した後でも、今後の撮影への参加を中止できることを確認しました。
5. 販売先へ提供済みの撮影データについては、削除を申し出た後も、すべてを回収・削除できない場合があることを確認しました。
