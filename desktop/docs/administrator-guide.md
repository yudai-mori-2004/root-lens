# 事業所の撮影データを管理する

現場監督者はRootLensへログインし、PCアプリで映像と音声を確認して承認した録画をアップロードします。
録画は、その事業所に結び付いたGoogle Driveの「承認済みデータ」へ保存されます。

## 事業所と担当者を登録する

協力先、事業所、承認権限を持つ担当者をRootLensへ登録します。担当者は個人のGoogleアカウントで
ログインします。RootLensはGoogleが返す変更されないアカウント識別子と事業所の所属を結び付け、
メールアドレスを継続的な本人識別子には使いません。

担当者を変更する場合は、事業所への所属を失効し、新しい担当者を招待します。
PCへ配布した秘密鍵を回収・交換する作業はありません。

## Google Driveを接続する

`rootlens.io` Workspaceの共有ドライブ内に事業所フォルダを用意し、RootLens管理者が管理導線から
一度だけGoogle Driveを接続します。Googleの更新トークンはRootLensサーバーで暗号化して保存します。Desktopアプリは
Driveの認証情報を保持せず、RootLens APIを通じて事業所と保存対象を指定します。

アップロード時、RootLensサーバーは一つのファイルにだけ使える再開可能アップロードURLを発行します。
DesktopアプリはそのURLへファイル本体を送り、RootLensサーバーがDrive上の保存先、識別情報、
サイズ、SHA-256を再確認してから完了とします。

## 合意と承認を管理する

撮影開始前に現場合意とスタッフ同意を取得します。署名済み文書はRootLens共有ドライブを原本とし、
RootLensは安定した記録ID、文書ハッシュ、状態、Drive上の所在を索引として保持します。

撮影後の承認は、特定の録画内容を確認し、販売先への提供を認める操作です。承認する担当者と
対象録画が記録で結び付くよう、ブラウザでパスキーによる電子署名を行います。承認対象の全ファイル、
事業所に適用される現場合意とスタッフ同意一式、承認文、担当者、時刻が一つの記録になります。詳しい設計は
[Consent evidence chain](../../document/v0.1.4/tasks/24-consent-evidence-chain/README.md)を参照してください。
