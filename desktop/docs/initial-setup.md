# PC の初回設定

事業所のPCを準備する担当者向けの手順です。現場担当者には、実際の画面に合わせた
[撮影データのアップロード手順](field-guide.md)を渡します。

## 現場監督者を登録する

協力先が撮影データの承認を任せる担当者をRootLensへ伝えます。RootLensは担当者の
Googleアカウントを事業所へ招待します。Googleアカウントは本人確認と事業所への所属確認に使い、
Google Driveの権限をPCアプリへ渡すためには使いません。

事業所のGoogle Driveは、協力先の管理者が一度だけRootLensへ接続します。接続情報は
RootLensサーバーで管理し、現場PCへDriveの認証情報やフォルダIDを配布しません。

## アプリへログインする

対象OS用のアプリをPCへ導入します。

- Windows 10 / 11（Intel / AMD）では、インストーラーを開き、画面に従ってインストールします。
- Macでは、DMGを開き、**RootLens Import.app**を「アプリケーション」へコピーして開きます。

アプリの**設定**から**Googleでログイン**を押します。既定のブラウザで、RootLensから招待された
Googleアカウントを選びます。ログイン完了後はアプリへ戻り、使用する事業所名を確認します。
ログイン情報はOSの資格情報ストアへ保存されます。

## 接続・再生・アップロードを確認する

アップロードしてよいテストデータを使い、実際に使うPCで次を確認します。

- 起動直後の録画一覧が空である。
- スマートグラスをUSBでつなぎ、**接続**を押すと、未アップロードの録画が表示される。
- 録画の映像と音声を再生できる。
- **アップロード**を押すとブラウザに対象録画と承認文が表示される。
- 初回は担当者のパスキーを登録でき、その後はパスキーで署名して承認できる。
- 承認後にアプリへ戻るとアップロードが始まり、完了後に一覧から外れる。
- 事業所の「承認済みデータ」に4ファイルが揃う。
- 保存確認後に、対象録画がスマートグラスから削除される。
- 通信やUSB接続が中断しても、再接続後に処理を再開できる。
- 別の事業所へ所属しないアカウントでは、その事業所を選べない。

使用したPC、OS、アプリの版、Googleアカウント、事業所、確認日時と結果を記録します。
