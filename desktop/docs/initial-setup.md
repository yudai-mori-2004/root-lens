# PC の初回設定

事業所の PC を準備する担当者向けの手順です。現場担当者には、実際の画面に合わせた
`アップロード手順説明.pdf` を渡します。

## 事業所の設定を用意する

事業所名、アップロード先の「承認済みデータ」、その事業所専用のサービスアカウント情報を
`rootlens-site.json` にまとめます。サービスアカウントの書き込み先を、その事業所のフォルダ内に限定します。
[アクセス権と設定ファイルの管理](administrator-guide.md)

事業所のフォルダに、アップロード手順説明、対象 PC 用のアプリ、`rootlens-site.json` を置きます。
設定ファイルを取得できる担当者は、事業所からアップロードを任された方に限定します。

## アプリを設定する

対象 OS 用のアプリを PC に導入します。

- Windows 10 / 11（Intel / AMD）では、ダウンロードしたファイル（`.exe`）を開き、画面に従ってインストールします。スタートメニューから **RootLens** を開きます。
- Mac では、ダウンロードしたファイル（`.dmg`）を開き、**RootLens Import.app** を「アプリケーション」へコピーして開きます。

Windows で「WindowsによってPCが保護されました」と表示された場合は、事業所の Drive から取得した
インストーラーであることを確認し、**詳細情報** → **実行**を選びます。実行できない場合は RootLens の担当者へ確認してください。

アプリの **設定** → **事業所の設定を読み込む** から `rootlens-site.json` を選びます。
事業所名とアップロードの設定が正しいことを確認します。設定は PC に保存されます。

## 接続・再生・アップロードを確認する

アップロードしてよいテストデータを使い、実際に使う PC で次を確認します。

- アプリを起動した直後は、録画一覧が空になっている。
- スマートグラスを USB でつなぎ、**接続**を押すと、Google Drive に未アップロードの録画が一覧に表示される。
- 左の一覧から選んだ録画を右の画面で再生でき、映像と音声を確認できる。
- **前の録画**・**次の録画**で移動できる。
- **アップロード**を押すと進捗が表示され、完了後に対象の録画が一覧から外れる。
- その事業所の「承認済みデータ」に、対象の録画と4ファイルが揃っている。
- 保存を確認した録画が、スマートグラスから削除される。
- 通信が中断した場合に、状態を確認してアップロードをやり直せる。
- Driveへの保存後にUSBが抜けても、次の接続で端末からの削除を再試行できる。
- USB をつなぎ直して **接続**を押しても録画が重複せず、アップロード済みの録画は表示されない。

使用した PC、OS、アプリの版、事業所設定、確認日時と結果を記録します。

## 現場担当者へ伝える

事業所のフォルダのリンクと、スクリーンショット付きの `アップロード手順説明.pdf` を渡します。
撮影前に本人の署名を得る手続、アップロードが事業所の承認になること、操作に困ったときの連絡先も伝えます。

PC や端末を別の事業所で使うときは、保存した録画の撮影場所と事業所設定を確認します。
担当者や PC が変わったら、アクセス権と設定ファイルの配布先を見直します。
