# PC の初回設定

事業所のPCを準備する担当者向けの手順です。現場担当者には、実際の画面に合わせた
[撮影データのアップロード手順](field-guide.md)を渡します。

## 現場監督者を登録する

事業所の現場監督者または管理者が、撮影データの承認を任せる担当者を事業所へ登録し、
招待リンクを渡します。担当者は招待リンクからSMS認証と撮影参加への同意を完了します。

RootLensが管理する共有ドライブに事業所ごとの保存先を用意します。現場PCにDriveの認証情報や
フォルダIDは配布しません。対象事業所の現場監督者または管理者として登録された電話番号でログインした場合にだけ、
RootLensサーバーが対象事業所を照合し、承認済みデータのアップロードを受け付けます。

## アプリへログインする

対象OS用のアプリをPCへ導入します。

- Windows 10 / 11（Intel / AMD）では、インストーラーを開き、画面に従ってインストールします。
- Macでは、DMGを開き、**RootLens Import.app**を「アプリケーション」へコピーして開きます。

アプリの**設定**から**SMSでログイン**を押します。既定のブラウザで電話番号とSMS認証コードを入力します。
ログイン完了後はアプリへ戻り、使用する事業所名を確認します。
ログイン情報はアプリを閉じると破棄され、次の起動時には再びSMS認証が必要です。

## 接続・再生・アップロードを確認する

アップロードしてよいテストデータを使い、実際に使うPCで次を確認します。

- 起動直後の録画一覧が空である。
- アプリを閉じて開き直した後、SMS認証から始まる。
- スマートグラスをUSBでつなぎ、**接続**を押すと、未アップロードの録画が表示される。
- 先に準備できた録画を、残りの録画のコピー中に確認・アップロードできる。
- 録画の映像と音声を再生できる。
- **アップロード**を押すとブラウザに対象録画と承認文が表示される。
- SMSで本人確認された担当者が、ブラウザに表示された対象録画と承認文を確認して承認できる。
- 承認後にアプリへ戻るとアップロードが始まり、完了後に一覧から外れる。
- 事業所の「承認済みデータ」に4ファイルが揃う。
- 保存確認後に、対象録画がスマートグラスから削除される。
- 通信やUSB接続が中断しても、再接続後に処理を再開できる。
- 別の事業所へ所属しない電話番号では、その事業所を選べない。

使用したPC、OS、アプリの版、担当者、事業所、確認日時と結果を記録します。
