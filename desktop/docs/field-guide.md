# 撮影データのアップロード手順

| 項目 | 内容 |
|---|---|
| 事業所 | ［事業所名］ |
| 困ったときの連絡先 | ［担当者名・連絡先］ |

## 初めて使うとき

RootLensをPCへインストールして開きます。**設定**から**SMSでログイン**を押し、
事業所に登録された電話番号とSMS認証コードでログインします。表示された事業所名を確認してください。
ログインが有効な間は、アプリを開き直してもSMS認証は不要です。

## 録画を取り込む

スマートグラスの録画を止め、保存が終わるまで待ちます。電源を入れたままUSBケーブルでPCにつなぎ、
**接続**を押します。スマートグラス内の未アップロードの録画を順に確認用としてコピーし、準備できた録画から一覧に表示します。残りの録画をコピーしている間も、表示された録画を確認してアップロードできます。
Driveに接続できないときも録画の取り込みと確認はできます。アップロードは接続をやり直した後に行ってください。

## 映像と音声を確認する

録画を選び、映像と音声を確認します。撮影を避けるよう指定された内容が含まれる場合や、
映っている方・声が入っている方の同意を確認できない場合は、アップロードせずRootLensへ連絡してください。

## 承認してアップロードする

内容を確認した録画を選び、**承認へ進む**を押します。アプリ内に承認内容が表示されたら、
対象ファイルと承認文を確認して**確認して提供を承認**を押します。その後、自動で
アップロードが始まります。完了するまでアプリを閉じたり、
USBケーブルを抜いたりしないでください。保存を確認できた録画はスマートグラスから削除されます。
PCに取り込んだ確認用コピーも削除されます。
途中で中断した場合は、つなぎ直して**接続**を押してください。送信完了を確認できなかった録画は端末に残り、PCを交換しても端末から取り直せます。アプリを閉じるとPCの確認用コピーは削除されます。

この承認操作は、その録画を販売先へ提供することへの事業所の承認です。
事業所から承認を任された方が操作してください。
