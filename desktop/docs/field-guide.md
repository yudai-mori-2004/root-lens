# 撮影データのアップロード手順

| 項目 | 内容 |

## 初めて使うとき

RootLens ImporterをPCへインストールして開きます。**SMSでログイン**を押し、
事業所に登録された電話番号とSMS認証コードでログインします。表示された事業所名を確認してください。
ログインが有効な間は、アプリを開き直してもSMS認証は不要です。

## 録画を取り込む

スマートグラスの録画を止め、保存が終わるまで待ちます。電源を入れたままUSBケーブルでPCにつなぎ、
右上の**端末を再確認**（更新アイコン）を押します。スマートグラス内の未アップロードの録画を順に確認用としてコピーし、準備できた録画から一覧に表示します。残りの録画をコピーしている間も、表示された録画を確認してアップロードできます。
Driveに接続できないときも録画の取り込みと確認はできます。アップロードは接続をやり直した後に行ってください。

## 映像と音声を確認する

録画を選び、映像と音声を確認します。撮影ミスや作業中の手元が確認できない録画、撮影を避ける対象や同意していない人が含まれる録画は承認せず、ゴミ箱ボタンから削除してください。削除前に確認画面が表示され、端末からも削除されます。
**保存未完了**や**取り込みエラー**の録画も一覧から選んで削除できます。これらは承認できません。USB接続が切れたときは端末をつなぎ直し、右上の更新ボタンで再確認してください。

## 承認してアップロードする

内容を確認した録画を選び、**提供を承認**を押します。アプリ内に承認内容が表示されたら、
対象ファイルと承認文を確認して**確認して提供を承認**を押します。その後、自動で
アップロードが始まります。完了するまでアプリを閉じたり、
USBケーブルを抜いたりしないでください。保存を確認できた録画はスマートグラスから削除されます。
PCに取り込んだ確認用コピーも削除されます。
途中で中断した場合は、つなぎ直して**端末を再確認**を押してください。送信完了を確認できなかった録画は端末に残り、PCを交換しても端末から取り直せます。アプリを閉じるとPCの確認用コピーは削除されます。

この承認操作は、その録画を販売先へ提供することへの事業所の承認です。
事業所から承認を任された方が操作してください。
